# Risk Scout

A lightweight credit risk scoring engine driven by an integrated Python pipeline and a local database backend.

## The Tech Stack
* **Language:** Python 3 (Pandas, SQLite3 processing)
* **Database:** SQLite3 
* **Environment:** VS Code sandbox architecture

## Project Features
* Automates ingestion of customer profiles from flat-file CSV data.
* Normalises and structures financial records into local relational database tables.
* Executes operational SQL queries to run algorithmic risk computations.
